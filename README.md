One image that sums up Tuesday 17 November 2026's world news — six stories
across conflict, markets, politics and health, drawn as a newspaper front
page. Every headline is a verified fact from that day (Reuters, AP, BBC,
PAHO/WHO, UN News).

`main.py` (Python 3.13, standard library only) draws the 1024x1024 PNG
itself — hand-written PNG encoder, embedded 5x7 bitmap font, no network —
and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Two runs produce
byte-identical output.
